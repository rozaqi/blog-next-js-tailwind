# Abdul Rozaqi Wildan — Engineering Portfolio & Blog

Personal engineering portfolio and technical blog built with **Next.js**, **Tailwind CSS**, and **MDX**.

Live website: [rozaqi.net](https://rozaqi.net)

---

## 🚀 Overview

- **Positioning:** Systems Operations Engineer specializing in Linux Infrastructure, Virtualization, Cloud Platforms, and Enterprise Storage.
- **Tech Stack:**
  - **Framework:** Next.js 12, React 18
  - **Styling:** Tailwind CSS, PostCSS
  - **Content:** MDX (Markdown + JSX), Syntax Highlighting via Prism
  - **Visuals:** WebGL Shader (FluidOrb) & Responsive Avatars
  - **Standards:** WCAG AA Accessibility (100 Contrast Ratio)

---

## 🛠️ Development

Install dependencies:

```bash
npm install
```

Configure environment:

```bash
cp .env.example .env.local  # set NEXT_PUBLIC_SITE_URL=https://rozaqi.net
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
